YT Musicfast for Windows and Linux: third-party software in this package
=========================================================================

YT Musicfast itself is MIT-licensed (LICENSE). This package also contains:

libmpv: mpv (https://mpv.io), with FFmpeg (https://ffmpeg.org) and the libraries it is built with
  - Windows (libmpv-2.dll): built by https://github.com/shinchiro/mpv-winbuild-cmake with mpv's GPL
    parts and GPL libraries, so distributed under the GNU General Public License, version 3
    (GPL-3.0.txt). Its build scripts list every source it builds; the build used is named in
    .github/actions/libmpv-windows of https://github.com/MijaelFV/YTMusicfast at this release's tag.
  - AppImage and Flatpak: mpv, FFmpeg and libplacebo built from source without GPL parts, so
    LGPL 2.1 or later (LGPL-2.1.txt); the sources are named in desktop/packaging/linux/
    build-libmpv.sh and desktop/packaging/flatpak of the same repository. Their license files are
    in usr/share/doc (AppImage); the other libraries the AppImage bundles come from Debian 12,
    each with its copyright file in usr/share/doc (sources at https://sources.debian.org).

Velopack (Update.exe, UpdateNix and the update library in the app), MIT License, see
